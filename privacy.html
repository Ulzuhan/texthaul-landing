Privacy Policy

Last updated: May 14, 2026

TL;DR

TextHaul does not collect, transmit, or store any of your data on external servers. All processing happens locally in your browser. We have no access to your screenshots, extracted text, or browsing history.

1. Information We Do Not Collect

TextHaul is designed to be completely private. We do not collect or have access to:

  • Screenshots or images you capture
  • Text extracted via OCR
  • Web pages you visit or their URLs
  • Your browsing history
  • Personal identifiers or contact information
  • Usage analytics or telemetry data
  • Cookies or tracking data

2. Local Data Storage

All data created by TextHaul is stored locally on your device using your browser's IndexedDB storage. This includes:

  • Captured screenshots (as compressed images)
  • Thumbnail previews
  • Extracted OCR text
  • Tags and metadata you assign to captures
  • Extension settings (language preference, theme, etc.)

This data never leaves your device and is not accessible to us or any third party. You can delete all stored data at any time through the extension's Settings page or by uninstalling the extension.

3. OCR Processing

Optical Character Recognition (OCR) is performed entirely within your browser using the open-source Tesseract.js library. Key points:

  • All OCR language models are bundled locally with the extension
  • Processing occurs in a Web Worker within your browser
  • No image data is transmitted to external servers for OCR
  • No code is loaded from remote servers

4. Permissions

TextHaul requests the following Chrome permissions, each used solely for the stated purpose:

Permission Purpose
activeTabCapture the currently visible tab
storageSave captures and settings locally
unlimitedStorageAllow larger local storage for images
contextMenusAdd right-click capture options
scriptingInject capture tools into pages
alarmsSchedule automatic old data cleanup
notificationsShow capture completion alerts
clipboardWriteCopy extracted text to clipboard
<all_urls>Capture content from any webpage

5. Third-Party Services

TextHaul does not integrate with any third-party analytics, advertising, or tracking services. The extension does not make network requests to external APIs. The only external resources are:

  • The Chrome Web Store (for installation and updates)
  • GitHub (if you choose to view the source code repository)

7. Changes to This Policy

We may update this Privacy Policy from time to time. Any changes will be posted on this page with an updated revision date. Since TextHaul does not collect contact information, we cannot notify users directly of policy changes.

8. Contact
